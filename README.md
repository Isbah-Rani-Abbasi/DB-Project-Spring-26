# 📚 Course Registration System

A full-stack web application that allows students to register and enroll in courses, and enables admins to manage the entire course catalog — built with **React**, **Python/Flask**, and **Supabase**.

---

## 🚀 Features

### 👩‍🎓 Student
- Register and log in securely
- Browse available courses
- Enroll in courses
- View personal timetable/schedule

### 🛠️ Admin
- Add, update, and delete courses
- Manage student enrollments
- View all registered students and course capacities

###👩‍🏫 Teacher

View assigned courses
View enrolled students
---

## 🧰 Tech Stack

| Layer      | Technology          |
|------------|---------------------|
| Frontend   | React               |
| Backend    | Python / Flask      |
| Database   | Supabase (PostgreSQL) |
| API        | RESTful APIs        |

## ⚙️ Setup & Installation

### Prerequisites
- Node.js & npm
- Python 3.x
- Supabase account

### 1. Clone the repository
```bash
git clone https://github.com/Isbah-Rani-Abbasi/DB-Project-Spring-26.git
cd DB-Project-Spring-26
```

### 2. Backend Setup
```bash
cd backend
pip install -r requirements.txt
python app.py
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm start
```
